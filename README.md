The Loki Programming Language
=============================

The language to close the gap between humans and machines.

## Design Principles

- Interoperability with C ABI
- (non-AI) Code generation is encouraged, rather than C++ templates.
- Familiar for C programmers
- Performance is key.
- Batteries included standard library
- Zero allocation standard library
